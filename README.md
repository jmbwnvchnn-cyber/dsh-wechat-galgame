# 微信群 AI Galgame

把 AI 角色放进微信群，让群友通过聊天和剧情选项体验 Galgame。

这是一次个人群聊实验的现有版本，现将源码和便携包整理出来，供大家自行体验和修改。**目前暂时没有继续开发的计划，不承诺持续更新、安装服务或微信新版本兼容。** 欢迎反馈和提交改进，处理时间不固定。

## 可以做什么

- 通过真实 @ 角色触发回复，支持 DeepSeek 等兼容 OpenAI Chat Completions 的模型接口。
- 每位群友有独立路线与好感度，好感范围为 -100～100；同一局第一位达到 100 的玩家成为唯一胜者。
- 随机事件结合近期同群话题生成；群友分别领取自己的选项并选择，可能加分、减分或不变。
- 提供本地网页管理台，可修改角色、查看路线和管理记忆。

玩家路线分别保存；近期同群消息可用于随机事件背景。**不要把它理解成已经完整模拟全群人际关系、竞争意识或吃醋。**

## 普通用户：下载便携包

请打开本仓库右侧的 **Releases**，下载 `gal-portable-v0.1.0.zip`，完整解压到一个新文件夹。

> GitHub 的 `Code → Download ZIP` 和 Releases 自动生成的 `Source code (zip)` 都是源码，不包含运行环境。第一次体验请下载名字以 `gal-portable` 开头的附件。

准备 Windows、已登录的微信桌面客户端，以及自己的模型地址、模型名称和 API 密钥。便携包已附 Node.js 和 Python，不需要先安装开发环境。微信客户端更新可能影响运行，不保证适配所有版本。

1. 双击 `start-service.bat`（或 `start.bat`），浏览器会打开本地设置向导。
2. 检测并选择自己的微信账号，搜索和勾选已经获得成员同意的测试群。
3. 填写模型地址、模型名称和密钥，按需点击“测试模型”。模型调用费用由你自己的服务账号承担。
4. 保存设置，再明确点击“启动桥接”。保存本身不会开始监听。
5. 在管理台设置角色名字和人设，让其他群成员通过微信真正的 @ 功能提及角色进行测试。

注意：运行机器人微信账号自己发出的消息会被过滤，请让另一个群成员参与测试。

停止时双击 `stop-service.bat`，或在设置页停止桥接。不要同时运行多份桥接。

## 群内玩法

真实 @ 角色后输入以下内容（`@角色` 仅是写法示意）：

| 内容 | 作用 |
| --- | --- |
| 普通聊天 | 与角色互动，可能改变好感度 |
| `/好感` | 查看自己的分数和关系阶段 |
| `/事件` | 领取自己的事件选项或查看剩余时间 |
| `/选择 A` | 提交自己的选择，也可使用 B 或 C |
| `/记忆` | 查看自己的长期记忆 |
| `/记住 内容` | 保存自己的信息 |
| `/忘记 全部` | 删除自己的长期记忆及相关近期对话 |
| `/帮助` | 查看帮助 |

随机事件默认在有效普通互动至少 5 次后开始概率触发，第 12 次保底；同群有 30 分钟冷却，每天最多 3 次。事件有效 10 分钟，每人各选一次。好感计分还受每日上限、冷却和重复内容限制，不能靠重复刷屏直接通关。详见 [玩法与管理说明](docs/gameplay.md)。

## 隐私和使用范围

- `config.json` 保存本机设置和模型密钥；`data/` 可能包含微信数据库密钥、解密缓存、游戏记录、记忆和日志。**这两个位置不要上传 GitHub，也不要随便发给别人。**
- 接入在线模型后，为生成回复，程序会把必要的聊天内容、角色设定、玩家关系/记忆及受限的近期同群上下文发送给你配置的模型服务。它不是全程离线运行的工具。
- 群成员应提前知情同意。只在自己的测试账号和获准的测试群使用。
- 网页服务仅监听本机回环地址；请保持本地使用，不要映射到公网。

详情见 [隐私与数据说明](docs/privacy.md) 和 [微信桥接说明](docs/wechat-setup.md)。

## 源码使用和修改

源码仓库不包含 `runtime/`，而当前的启动器和设置向导依赖该目录。最方便的方式：

1. 下载同版本的便携包，将里面完整的 `runtime` 文件夹复制到源码根目录。
2. 双击源码目录中的 `start-service.bat`。
3. 修改 `src/`、`web/` 等代码后，停止服务再重新启动。

随附 Node.js 要求版本不低于 22；桥接使用 Python，当前便携包为 Python 3.12。Python 直接依赖见 `bridge/requirements.txt`。目前没有提供从零自动下载运行环境的脚本；不要把只装好系统 Python 等同于已经满足设置向导要求。

纯服务逻辑的检查可在项目根目录执行（使用系统 Node.js，或将 `node` 换成 `runtime\node\node.exe`）：

```powershell
node scripts/verify.js
node scripts/verify_context_events.js
node scripts/verify_negative_affection.js
node scripts/verify_setup.js
```

这些检查使用模拟消息，不需要连接真实微信或在线模型。更多代码结构与检查说明见 [开发说明](docs/development.md)。

## 已知限制

- 微信桥接依赖非官方接口和桌面自动化；更新客户端后可能失效。
- 主要面向 Windows，未验证 macOS/Linux。
- 不保证模型回复、剧情或评分始终合理；不支持保证胜率、指定胜者或付费加分。
- 图片、文件、链接卡片等不会作为普通文字聊天处理；不补发离线消息。
- 开源发布整理不等于已经在其他电脑和所有微信版本上完成测试。
