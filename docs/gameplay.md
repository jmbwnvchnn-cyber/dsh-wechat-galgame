# 小鲸的故事

在微信测试群里陪大家玩 Galgame：每位群友有独立路线，第一位达到 100 好感度的玩家成为唯一胜者。请只在自己的测试小号和已获同意的测试群使用。

## Windows 首次使用

1. 解压完整分享包，双击 `start-service.bat` 或 `start.bat`（两个入口使用相同的启动流程）。包内已附 Node.js 与 Python，无需另行安装。
2. 首次启动会打开设置向导。登录微信后检测账号，搜索并勾选群聊，再填写兼容 OpenAI Chat Completions 的模型地址、名称和密钥。
3. 可选：点击“测试模型”检查连接。此操作会向模型服务发送一次测试请求。
4. 点击“保存设置”，确认模型与群聊后，再明确点击“启动桥接”。桥接启动后会监听选定群消息，并可能操作微信窗口发送回复。
5. 之后双击 `start.bat` 会直接打开故事管理台。要调整账号、群或模型，点管理台中的“设置向导”。

账号和群检测会读取所选微信账号的本地联系人数据库，不会发送消息。群名偏好（若有）只用于本机搜索框预填，不会写入分享包。设置、密钥和运行数据保存在本机的 `config.json` 与 `data/`；请勿分享这些内容。

## 管理故事

管理台可编辑角色人设、查看路线与动态、纠正或删除长期记忆。只有测试群成员真实 @ 角色时才触发回复；纯文字输入“@昵称”不算。修改人设会在后续对话中生效。

支持普通文字和“引用一条消息后再真实 @”的文字回复。引用时按本次新输入处理，旧引用中的命令不会被当成新命令。图片、文件和链接卡片尚不作为普通文字聊天触发。

好感范围为 **-100～100**：负分依次表现为疏远、戒备、反感，正向依次为初识、熟悉、亲近、心动、攻略成功。角色会结合人设、该玩家记忆和当前关系改变态度，负分仍可通过后续互动修复。管理台以 0 为中线显示正负好感。

群里真实 @ 角色后，可输入 `/好感` 查看分数、关系阶段和加分限制，`/帮助` 查看命令，`/记忆` 查看自己的长期记忆，`/记住 内容` 保存事实，`/忘记 关键词` 或 `/忘记 全部` 删除记忆。这些命令不调用模型、不计分。

默认同一玩家跨群正向加分冷却 120 秒，中国时区每天最多增加 15 分；滚动 24 小时内的重复或近似内容不重复涨分，过短内容也不加正分。负分不受正向限额影响；仍可继续聊天。相关设置见 [接口与游戏规则](webhook.md)。

整局重置会清空路线好感度和近期对话、解除胜者锁定；长期记忆与防刷记录保留。删除记忆会同时清除相关近期对话。请在管理台确认后再执行这些操作。

## 随机事件

默认开启，可在设置向导关闭。每群正常互动至少 5 次后，每次有 20% 概率随回复出现事件，第 12 次保底；同群冷却 30 分钟，中国时区每天最多 3 次。事件进行中不会出现新事件，也不会在无人聊天时主动刷屏。

新事件结合角色人设、当前群的近期聊天生成，创建事件时会同时给触发玩家生成个人选项。其他群友真实 @ 角色后发 `/事件` 领取自己的 A/B/C，选项和隐藏结果结合本人的关系、记忆与互动记录确定。再发 `/选择 A`（或 B/C）、`选A` 或单独 `A` 即可；也支持 1/2/3。没有领取不能直接用别人的字母。重复领取、重启均不会刷新题目；公开文字仍可能被模仿，这种机制主要降低机械照抄收益。

**每个事件有效 10 分钟，每位群友各选一次**，领取不会延长截止时间。用 `/事件` 查看自己的选项和剩余时间。选择结果可能加分、减分或不变，结算后公开显示自己的实际好感变化。创建事件复用普通聊天的同一次模型请求；其他玩家首次领取会额外请求一次当前配置的模型，随后缓存，提交选项不再调用模型。生成异常时会以当前话题和关系构造本地选项。

为衔接当时的话题，桥接会给通过真实 @ 验证的请求附带最多 8 条、10 分钟内的当前群短文本，并限制整体消息长度；不混入其他群或私聊。对话只作为叙事资料，长期记忆仍按各人保存。更正或遗忘会过滤旧上下文；已经领取的旧个人事件可能作废，不能借此刷新选项。升级前已发布的旧格式事件会按原规则结束。

重复选择、更换选项、超时或无效选项不加减分，也不调用模型。事件加分计入每日正向上限，不受普通聊天冷却影响。重启保留到期时间与参与记录；重置路线不能重新参与同一个事件；整局重置清除活动事件，但保留当天触发次数与群冷却。第一位达到 100 的玩家仍是唯一胜者。

## 停止和排障

在设置向导点击“停止桥接”可停止监听；双击 `stop-service.bat` 可关闭 gal 服务和桥接，保留好感、记忆和设置，微信不会关闭。也可在启动窗口按 Ctrl+C。关闭后，重新双击 `start-service.bat` 即可启动服务，再在设置页启动桥接。请保持微信登录，首次启动桥接时只保留一个可见的微信主窗口。运行中会始终使用已经绑定的窗口，其他窗口出现不会自动更换发送账号；原窗口关闭或失效时停止发送，需重新启动桥接确认账号。桥接依赖非官方微信接口，微信更新可能影响兼容性。

启动失败时，确认分享包已完整解压且 `runtime` 文件夹仍在。双击 `diagnose-bridge.bat` 可检查依赖与本地配置，不会连接模型、读取微信数据库、监听群聊或发送消息。更多桥接说明见 [微信桥接说明](wechat-setup.md)。

群里收到“回复服务暂时繁忙”表示模型接口临时失败，并非角色不愿意回复。模型请求遇到 HTTP 429 或 5xx 时会等待 700 毫秒重试一次；持续失败不计好感，也不会自动重发微信消息。管理台会显示最近一次模型请求的安全错误码，成功后自动清除。可稍后重新真实 @ 角色发送一条新消息。
